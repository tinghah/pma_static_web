# Pouchen Myanmar (B150) PCM PCaG PCB IT Portal

A high-end, multi-language static web portal for the IT Team at Pouchen Myanmar.

## 🚀 Live Site
Check it out here: [https://tinghah.github.io/pma_static_web/](https://tinghah.github.io/pma_static_web/)

## 🛠️ Tech Stack
- **Framework**: Vite + React 19
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **i18n**: i18next (English, Burmese, Traditional Chinese, Simplified Chinese, Vietnamese)

## 📁 Key Sections
- **About Us**: Pouchen history and global presence.
- **IT Operations**: Factory 4.0 ecosystem (SAP, MES, WMS, MPS).
- **AI & Innovation Lab**: AI Agent workflows and Vibe Coding.
- **Support Desk**: Production factory support systems.
- **Team**: Meet our IT innovators.

## 📦 Local Development
```bash
npm install
npm run dev
```

## 🏗️ Deployment
Automatically deployed to GitHub Pages via GitHub Actions on push to `main`.
